# 03 论文精读

> 目标：对单篇文献产出结构化精读卡，吃透问题、方法、证据、局限与对自己课题的启发。先声明读到了什么层级，绝不假装读过全文。

## 一、先判断证据级别

拿到文献先确认你实际掌握的内容，并在卡片顶部声明：

- **全文**：可读完整正文、图表、补充材料。
- **局部正文**：只有部分章节/页面。
- **仅摘要**：只有 abstract。
- **仅标题**：连摘要都没有。

只有摘要/标题时，明确写"**仅基于摘要（或标题与摘要）判断**"，并弱化关于实验细节、机制的断言。局部正文要区分"原文明确给出"与"由局部内容推测"。

## 二、精读卡模板

```
# 文献精读卡

## 覆盖范围说明
证据级别：全文 / 局部 / 摘要 / 标题；语言、来源、年份

## 1. 基本信息
- 题名 / 作者 / 期刊 / 年份 / DOI
- 文献类型：实验研究 / 综述 / 学位论文 / 标准 / 专利

## 2. 研究问题与背景
- 要解决什么问题？为什么重要？
- 针对的是哪类材料、什么服役场景？

## 3. 材料与试样
- 材料体系、成分、状态（供货态/热处理态）
- 试样形式、尺寸、取样方式、分组、重复数

## 4. 制备 / 实验 / 焊接方法
- 工艺路线、关键参数（如焊接方法、热输入、坡口、保护条件）
- 热处理制度、设备型号（若给出）

## 5. 表征手段与测试
- 用了哪些表征（金相、SEM/EBSD/TEM、XRD、硬度等）
- 力学/性能测试方法、标准、温度、试样取向

## 6. 关键结果与指标
- 关键数据（带数值、单位、条件、误差/离散度）
- 组织观察与性能之间的对应关系
- 作者给出的机制解释

## 7. 主要结论
- 用 2–4 条概括，区分"数据支持的结论"与"作者推断"

## 8. 证据强度评估
- 实验设计是否严谨、样本量是否足够、有无对照
- 数据是否自洽、有无统计检验、条件是否交代清楚

## 9. 优势
- 方法、数据或思路上的亮点

## 10. 局限与复现难点
- 作者自承的局限 + 你看出的问题
- 复现所需但文中缺失的条件/参数/设备
- 结果的适用边界

## 11. 对我课题的启发
- 可借鉴的工艺/表征/论证方式
- 可对比的数据、可引用的结论
- 需要警惕或进一步验证之处
- 与我研究的异同（体系/条件/指标）
```

## 三、未知信息处理

- 实验条件、参数、指标、结果**未在输入中明确给出的，直接标"未知/文中未给出"**，不补全想象。
- 论文的 claim 不直接改写成既定事实；转述时保留作者的限定条件与对冲词。
- 不编造数据、机制、开源状态、设备型号或"作者未说明"的内容。

## 四、阅读优先级三档

判断一篇文献值不值得投入时间，只用以下三个标签之一：

- **值得精读**：与课题高度相关、证据扎实、方法或数据可直接借鉴/对比。
- **值得速读**：部分相关，抓摘要+关键图表+结论即可。
- **可暂缓**：相关性低或证据弱，先存档。

快速筛文献时，保留精读卡字段但逐项压缩长度，重点看：问题、材料体系、关键指标、结论、与自己的相关点。

## 五、判断复现难点的要点

- 关键工艺参数是否给全（窗口而非单点时是否说明取值）。
- 试样制备、取样位置与取向、测试标准是否明确。
- 数据是否给离散度/重复次数，图是否可读、有无原始数据。
- 所用设备、试剂、软件是否常规可得。
- 机制结论是否有直接证据，还是仅为推测。

## 六、证据与表述约束

- 不假装读过未提供的全文；信息不足先在卡片顶部声明。
- 基于摘要的判断，不对实验设计与机制下强结论。
- 引用具体数值时连同条件、单位一起记录，避免断章取义。
