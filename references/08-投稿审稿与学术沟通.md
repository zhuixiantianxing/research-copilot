# 08 投稿、审稿与学术沟通

> 覆盖论文收尾与日常学术沟通：cover letter、模拟审稿与评审意见、rebuttal 回复、组会周报、学术报告与海报、科研图表与机制图。

---

## 一、投稿信 Cover Letter

写给编辑，简洁专业（通常半页以内）：

1. 论文题目、类型与投稿栏目。
2. 用 2–4 句说明：研究问题、核心方法、最关键的结果与贡献（具体、不夸大）。
3. 为什么适合该期刊、与该刊范围和读者的关系。
4. 声明：原创、未一稿多投、全体作者同意、无利益冲突；按需说明数据/代码可得性。
5. 推荐/回避审稿人（如期刊要求，仅按规定、客观）。
- 不重复摘要全文，不使用夸张形容词；语气尊重、客观。

投稿前按期刊清单核对：稿件与摘要字数、文件格式、图表、参考文献、版权与伦理表、 highlights / graphical abstract、补充材料、作者信息。

---

## 二、模拟审稿 / 撰写评审意见

当用户想"挑毛病、判断能不能投"或练习写评审时，以审稿人口吻，**只看不改、有据有节**：

### 评审结构
1. **总体评价（summary）**：论文做了什么、贡献大小、是否在期刊范围。
2. **主要优点**。
3. **主要问题（major）**：影响结论成立的硬伤——论证缺口、实验/对照不足、数据自洽、机制证据、可复现性。
4. **次要问题（minor）**：表述、术语、图表、引用、格式、错字，逐条编号。
5. **给编辑的建议**：接收 / 小修 / 大修 / 拒稿，并简述理由。

### 材料学重点检查
- 试样、工艺参数、设备与标准是否给全、可复现；样本量与重复、误差/统计。
- 组织表征是否足以支撑机制结论；性能数据是否与组织观察对应。
- 有无必要对照、不同条件/位置/温度的覆盖；数据是否自洽、有无回避不利结果。
- 结论是否超出数据；图表坐标、单位、标注是否准确。

### 评审语气
- 客观、建设性，就事论事；批评指向稿件而非作者，不使用贬低或情绪化语言。
- 区分"必须解决的问题"与"建议/个人偏好"。

## 三、审稿回复 Rebuttal / Response

处理 reviewer comments 与 meta-review，重点是拆 concern、区分**补实验 vs 澄清**、保持专业克制。

### 工作流
1. 逐位 reviewer 拆分意见，再汇总跨 reviewer 的**共性 concern**（共性问题往往是关键）。
2. 给每条意见分类：
   - **必须补实验/补数据**的；
   - **更适合澄清/改写表述**的；
   - 建议性、可说明取舍的。
3. 若 reviewer 之间意见冲突，单独指出、**不强行统一**；meta-review 若压住了某些意见，优先围绕 meta-review 组织总体策略。
4. 按"原文意见 → 回复 → 文中改动（位置/引文）"逐条回应。

### 回复原则
- **不编造实验、消融或额外分析结果**；没做的实验写成"计划/在补充材料中说明/作为后续工作"，绝不写成已有结果。
- 不假装已补完，不使用对抗、情绪化、讽刺语言。
- 不把误解归咎于 reviewer 能力，改写为"感谢指出，论文已在 X 处更清楚地说明……"。
- 对每条意见都回应（哪怕不完全采纳，也礼貌说明理由与依据）。
- 回复中清楚标出修改位置（页码/章节/行号），方便核对。

### 回复语气示例
- "We thank the reviewer for this insightful comment. （感谢审稿人的宝贵意见。）"
- "为回应这一问题，我们补充了……（见补充材料图Sx / 修订稿第x节），结果显示……"
- "我们同意原表述不够清晰，已修改为……"

## 四、组会汇报与周报

避免流水账，突出**结论、进展与需要讨论的问题**：

- 本期结论/进展（做了什么、得到什么结果，带关键数据）。
- 区分三类内容：**已有证据的结果 / 仍是猜测的判断 / 下一步要验证的假设**。
- 遇到的问题与卡点、已尝试的办法。
- 需要导师/组里决策或帮助的具体事项（明确列出）。
- 下一步计划与时间安排。

## 五、学术报告与海报

- **一页/一个观点**：每页幻灯片只承载一个核心信息，标题写成"行动标题"（直接给结论，而非"实验结果"这类名词标题）。
- 逻辑线：问题与背景 → 思路/方法 → 关键结果（图表清晰）→ 机制/结论 → 展望。
- 图表放大、坐标轴/单位/图例/来源完整；听众能看清的最小字号为准。
- 海报分区清晰、突出主图与结论；口头报告控制时长、留问答时间。
- 实际制作 PPT/海报时配合 PPT、可视化技能完成。

## 六、科研图表与机制图

### 图表内容规范
- 坐标轴有物理量、单位；图注可独立理解；数据点给误差与重复说明。
- 图中术语、数值与正文一致；对比图口径一致、基线公平。
- 显微图给标尺、必要的取向/区域标注；多子图风格统一。

### 机制图 / 示意图两步法
1. **先做逻辑架构（内容）**：用文字列出要表达的因果链/流程节点（如：焊接热循环 → 相变/组织演化 → 韧性变化），确定起点、中间环节、终点与箭头关系，删去与论点无关的元素。
2. **再做视觉渲染（表达）**：为每个节点选择合适的视觉元素（组织示意、图标、形貌），统一配色与箭头样式，保证黑白打印也可区分、图注能讲清机制。
- 机制图风格要符合学科与期刊习惯（材料学多为写实组织/流程示意，区别于计算机领域的框图风格）。
- 需要可编辑图形或成图时，配合 PPT / 可视化 / 图片生成技能完成；本技能负责逻辑与标注规范。

## 七、贯穿的证据与伦理约束

- 任何对外提交的材料（投稿、回复、评审）都不编造数据、结果、文献、基金或合作信息。
- 引用、署名、作者顺序、利益冲突、AI 使用披露按期刊规定与学术伦理处理。
- 与编辑/审稿人沟通始终客观、尊重、可核查。
