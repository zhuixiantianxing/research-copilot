# 05 论文规划与大纲

> 目标：在动笔前确定目标期刊/会议、学透样稿、设计结构合理的大纲，并用审稿人视角自评，避免"边写边改方向"。

## 一、确定目标发表平台

根据研究内容、数据完整度、创新性与时间要求选择：

- 期刊（领域内不同分区/影响因子/审稿周期）、会议、学位论文。
- 评估匹配度：主题范围、文章类型（全文/快报/综述）、是否接收该类实验研究、数据与篇幅要求、审稿周期、版面费。
- 不确定时列出 2–3 个候选并给出推荐理由，请用户确认（决策点）。
- 尽早下载目标期刊的 **Instructions for Authors / Author Guidelines**，作为格式与披露的权威依据。

## 二、样稿检索与学习

选取 **8–10 篇**该平台/同方向代表性论文，按时间维度分布：

- 近 6–12 个月 3 篇（捕捉最新风格与热点）
- 1–2 年 3 篇（当前主流标准）
- 高被引经典 2 篇（质量基准）
- 作者/团队 ≥5 个，视角与篇幅多样；相关性 ≥7/10。

### 从样稿中提取三类规律

1. **结构规律**
   - 章节如何组织（材料学多为 IMRaD：引言—实验—结果与讨论—结论）。
   - 摘要结构（背景/问题—方法—主要结果—结论）。
   - 各部分大致篇幅配比、图表数量与类型。
2. **风格规律**
   - 人称（we / 被动）、时态习惯、句子长短。
   - 引用密度与格式、术语用法、对冲方式。
3. **格式规范**
   - 字数/页数、参考文献格式、图表与单位规范、数据与伦理披露要求。

产出一份"目标期刊写作要点"，写作时对照。

## 三、设计章节结构

材料学实验类论文的典型骨架（按目标期刊调整）：

- 摘要（最后写）
- 1 引言：背景与需求 → 现有工作与不足 → 本文目的与工作
- 2 实验材料与方法：材料与试样、制备/焊接工艺、表征手段、测试方法
- 3 结果与讨论：组织观察 → 性能结果 → 机制分析（可分多节）
- 4 结论
- 参考文献、图表、补充材料

### 篇幅配比（参考值，以期刊为准）

- 引言：约 15–20%
- 实验方法：约 15–20%
- 结果与讨论：约 50–60%（论文主体）
- 结论：约 5–10%

### 确定论证/数据流

- 数据如何支撑结论：哪些图表对应哪个论点。
- 各节之间的逻辑递进；在哪里分析机制、在哪里回应引言提出的问题。
- 实验变量与对照如何呈现，是否需要补充数据。

## 四、大纲写到三级标题

每一节都标注：要回答的问题、要点、对应图表/数据、计划引用的文献、字数目标。例如：

```
## 3 结果与讨论（约 3000 字）
### 3.1 焊接接头的显微组织（约 900 字）
- 要点：各区组织特征、随热输入的变化
- 图表：图3 金相、图4 EBSD
- 引用：[X,Y] 关于焊接热循环与组织
### 3.2 低温冲击性能（约 1000 字）
- 要点：不同位置/温度的冲击功、断口形貌
- 图表：表2、图5
…
```

## 五、审稿人视角 7 维自评

大纲完成后，把自己当成审稿人，按 7 个维度各打 1–5 分（满分 35）：

1. **问题与论点清晰度**：研究问题、核心论点是否明确。
2. **论证完整度**：有无逻辑跳跃/缺口，关键前提是否成立。
3. **文献支撑**：关键工作是否覆盖，引用是否充分。
4. **方法清晰度**：实验/制备/表征是否交代清楚、可复现，方法选择是否合理。
5. **原创性表达**：贡献与差异点是否清楚。
6. **组织结构**：逻辑是否顺畅、配比是否合理。
7. **期刊契合度**：是否符合目标平台的范围、风格与格式。

- 通过线：**≥ 28/35（80%）**。
- 必须找出 3–5 个具体问题并给出可执行修改建议；对低于 4 分的维度，按"问题—严重度（高/中/低）—具体改法—预期提升"列出，优先改高严重度项。

## 六、质量门

- 目标平台与作者确认，写作要点已提取。
- 大纲细化到三级标题，含要点、图表、引用、字数。
- 审稿人自评 ≥28/35，高严重度问题已解决。
- 各部分字数之和等于目标总量，数据能支撑全部结论。
- 不达标先改大纲，不进入正文写作。

## 七、证据与表述约束

- 大纲中计划陈述的结论必须有对应的数据/图表支撑，缺数据先安排实验或弱化结论。
- 不为"看起来完整"而硬加不属于本研究的章节。
- 期刊格式要求以官方指南为准，样稿只用于学习规律。
